# Productivity Dashboard

A personal productivity dashboard built for daily use — combines task management, scheduling, goal tracking, notes, and a Pomodoro timer in one app. Supports light and dark mode.

## Tabs / Features

**Today**
Daily overview: next scheduled block, due-soon items, today's schedule (pulled from Timetable), quick task entry, today's goals, and daily stats (tasks done, focus time, streak, items due in 7 days).

**Assignments**
Add and track assignments with due dates. Includes overdue/due-soon filtering and a priority option.

**Timetable**
Add time blocks with title, subject, start/end time, and a custom color. Blocks can be set for "every week" or "this week only." Blocks scheduled for today automatically appear in the Today tab.

**Goals**
Two goal types: long-term goals and today's goals. Long-term goal progress is tracked with a slider showing completion percentage.

**Notes**
Add notes with custom colors for organization.

**Focus**
Pomodoro-style timer with three modes: Focus (25 min), Short Break (5 min), Long Break (15 min). Tracks this week's focus sessions.

**Data & Backup**
Export/import all data as JSON. Supports selectively clearing individual categories (assignments, timetable, long-term goals, daily goals, tasks, notes) or resetting focus stats. Full data reset also available.
